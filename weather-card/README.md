# 🌤 Weather Card

A beautiful, responsive weather widget built with pure HTML, CSS, and vanilla JavaScript. No frameworks, no build tools — just open `index.html` in your browser.

## Preview

- Search any city and instantly see temperature, humidity, wind speed, visibility, and feels-like.
- Toggle between °C and °F.
- Glassmorphism dark-mode UI.

## Getting Started

1. Get a **free API key** from [OpenWeatherMap](https://openweathermap.org/api).
2. Open `app.js` and replace `"YOUR_API_KEY_HERE"` with your key.
3. Open `index.html` in any modern browser.

```js
const API_KEY = "your_actual_key_here";
```
